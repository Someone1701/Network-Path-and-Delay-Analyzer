📖 How This Real Implementation Validates the Theoretical Model

1. Mathematical Delay vs. Physical RTT

In our simulation, hop delay was decomposed mathematically: $d = d_{trans} + d_{prop} + d_{queue} + d_{proc}$. In this live section, we measure empirical Round-Trip Time (RTT) of real packets traversing physical optical fibers and internet exchange points (IXPs).

2. Queueing Backlog Measured via Jitter

In the simulation, router queue buffers were modeled using an M/M/1/K queue. On the live internet, router queue backlog fluctuates from packet to packet, which directly produces the Jitter ($|\Delta RTT|$) displayed in the table above.

3. TTL Expiration & ICMP Time Exceeded

By sending probe packets with an incrementing TTL (Time-To-Live), intermediate routers decrement TTL to 0 and reply with ICMP Type 11 (Time Exceeded) packets, allowing this tool to discover and time every router on the physical transit path.

4. DAPS vs. Autonomous BGP Routing

Our simulation proved that DAPS reduces delay by dodging congested links. In the real Internet, packet forwarding between Autonomous Systems is dictated by BGP policies, making real-time telemetry crucial for detecting transit bottlenecks.
